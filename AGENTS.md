# Project rules

- The homepage hero is real HTML — `<Header />`, a real `<h1>`, real copy and
  button — over `public/curve_hero.webp` as a decorative background
  (`aria-hidden`, empty `alt`). Never use a screenshot or mockup of the page as
  the hero image: the lettering is baked into those pixels, so the page renders
  the headline twice and a phone shrinks the whole desktop layout to a quarter
  size. The daylight seawall photo is homepage-only; city pages keep their own
  night photographs.
